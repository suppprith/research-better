# A full run, with its output

`paper.md` is a short fake CS paper with defects planted on purpose. It is the
test fixture, and it is not subtle: it is a test instrument rather than a
writing sample. What is planted and where is documented in
[tests/fixtures/README.md](../tests/fixtures/README.md).

Everything in `output/` is what the tool actually printed, written by
`scripts/build_example.py` and regenerated by a test that fails on any
difference. Nothing here was typed out by hand. A repository about verifying
claims, carrying example output somebody wrote from memory, would be refuting
itself in its own text.

The run is offline against the responses recorded in `tests/fixtures/http`, so
it produces the same verdicts anywhere and asks nothing of OpenAlex.

| File | What it is |
| --- | --- |
| [`output/run.txt`](output/run.txt) | Every command and its summary line, in order |
| [`output/report.md`](output/report.md) | The one page, including what was not checked |
| [`output/trace.md`](output/trace.md) | Passages that may read as machine-written, with causes and fixes |
| [`output/reviewer-questions.md`](output/reviewer-questions.md) | What a reviewer would ask, unanswered |
| [`output/edits.md`](output/edits.md) | The proposed cuts, and the ones refused |
| [`output/edits.diff`](output/edits.diff) | The same as a patch |

## What to look at

**The report's "Not checked" section.** Six entries on a paper this small. One
of six cited works had retrievable full text, two sources could not be reached
for the overlap check, and two rhythm rules are switched off pending
calibration. A clean report with that section missing would be worth much less.

**The trace audit's second list.** Method paragraph 1 tripped the uniform
rhythm signal and was left alone, with the reason: it is methods prose, and
methods prose is uniform because a method is a list of steps. Six passages were
flagged and that one was not, which is the distinction the pass exists to make.

**The refusals in the edit ledger.** Three proposed cuts were dropped, each
with the rule that dropped it. The voice lock and the word budget refusing a
change is the mechanism working rather than a failure.

**The paragraph nothing touched.** Results paragraph 2, beginning "Recall at
ten rises from 0.62 to 0.71", carries numbers, a citation, and an explicit
negative result. Every pass leaves it alone. A tool that flags everything is
useless, so this paragraph is the one that shows the passes discriminate.

## Reproducing it

```
pip install -e ".[all,dev]"
python scripts/build_example.py
git diff --exit-code examples/
```

The last line is what CI runs. A change to any pass that changes this output
makes the repository's documentation wrong until it is regenerated, and the
build says so.
